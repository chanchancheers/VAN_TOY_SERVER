## 프로토콜
### | STX | Length | Type | Payload | ETX |  

### 구성
#### 1. 시작(2Byte)

- "PS" ( 0x5053 )

#### 2. Length (2Byte)
- Length = Payload Length + 5 Byte

#### 2. Message Type (1Byte)
| Type | 설명 |
|---------|----|
|1| 조회 |
|2| 등록 |
|3|수정|
|4|삭제|

#### 3. ETX (2Byte)
- "PE" ( 0x5045 )
